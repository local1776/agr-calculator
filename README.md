# agr-calculator
They say AGRs make more money. Well...the devil is in the details. 

## Maintenance

Version 1.4, November 19, 2026. Audit fixes: AGR retired pay counts drill points (10 U.S.C. 1405), a second-job card, both ends of a tour cut short, highest expected grade, TRICARE Reserve Select for Technicians from 2030, and FERS counted after inflation. One self-contained file (`index.html`): pay tables, math and page together, with fonts built in. It makes no network requests. Tests and build notes are in `tests/`.
